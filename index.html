Koneksi Google Spreadsheet

Masukkan URL Web App Google Apps Script yang sudah di-deploy.

Belum ada URL yang dikonfigurasi.

Penting: data kesehatan termasuk data pribadi. Jangan gunakan deployment publik untuk data medis nyata tanpa autentikasi dan pembatasan akses yang memadai.

Langkah konfigurasi

  1. Buat spreadsheet baru melalui sheets.new.
  2. Buka Ekstensi → Apps Script.
  3. Ganti isi Code.gs dengan kode yang disertakan pada file unduhan.
  4. Simpan, lalu pilih Deploy → New deployment → Web app.
  5. Pilih akun eksekusi dan akses sesuai kebutuhan privasi. Untuk demo, akses publik hanya digunakan dengan data dummy.
  6. Deploy, salin URL berakhiran /exec, lalu tempelkan ke kolom di sebelah kiri.

Spreadsheet akan memiliki dua sheet: Catatan_Kesehatan dan History_Obat. Header dibuat otomatis oleh Apps Script.
